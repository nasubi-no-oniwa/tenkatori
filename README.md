# 天下取りマース

戦国時代の日本を5000マスで奪い合う、全員参加の国盗り。なすびのお庭の作品。

- 遊ぶ：https://nasubi-no-oniwa.github.io/tenkatori/
- 管理画面：https://nasubi-no-oniwa.github.io/tenkatori/admin.html （管理のかぎは Fairies' Tower・エンピツライフと同じ）
- 終わり：2026年11月30日 23:59（日本時間）。または、どれかの陣営が2500マス（半分）を取ったとき

## 遊び方
- 10の問い（4択）に答えると、仕える武将（20人）が決まる。答えが同じなら必ず同じ武将
- 取れるのは、自軍の領地のとなりにある、ほかの陣営のマスか白いマス。1つ取ると次は1時間後（ためられない）
- 天守閣のマスは取れない（どの武将にも最低1マス残る）
- 3日に1回、マスがいちばん少ない武将のもとへ寝返れる（同じ数ならその中から選べる）。名前の頭に「寝返った」がつく
- 名前は「尾張の与作」の形。国は最初に仕えた武将の本拠の国で、あとから変えられない
- 掲示板は、陣営ごとの軍議（その陣営の人だけ）と、全体

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 画面と見た目（広告はスマホのときだけ、タイトルとマスを取ったあとの画面。`?noad=1` で広告なし、`?offline=1` でひとりで試す） |
| `admin.html` | 管理画面（ようす・掲示板を陣営ごとのタブで見る／なすPとして書く・質問と要望・記録と荒らし対応・お知らせ／一時停止） |
| `js/mapdata.js`・`data/map.json` | 5000マスの地図（`python3 tools/mkmap.py` で作った。公開後は作りなおさない） |
| `js/data.js` | 武将20人・診断10問・決まりの数字（`node tools/tune-quiz.mjs` で20人にまんべんなく当たるよう調整） |
| `js/kamon.js` | 家紋（線と図形だけで描く） |
| `js/net.js` | データベースとのやりとり（Firebase ft-blue の `tk` の下だけ。常時接続は使わない） |
| `js/map.js` | 2Dの地図（指で動かす・2本指で広げる） |
| `js/scene3d.js` | 3Dの場面（タイトルの立体の日本・のぼり旗） |
| `js/fx.js`・`js/pixelfx/` | ドット絵の演出（道具箱の pixelfx） |
| `js/i18n.js` | 4言語（日本語・英語・繁体中文・韓国語） |
| `database.rules.tk.json` | データベースのルール（`node tools/mkrules.mjs` で作る。GitHub に上げると自動で ft-blue に反映。鍵は `FT_BLUE_SERVICE_ACCOUNT`。ほかのゲームの部分はそのまま） |

## 試験
- `node test/rules-test.mjs`：ルール（にせのデータベースで）
- GitHub の上では、上げるたびに、本物の ft-blue の試験用の場所（`tkt`）で、同じ台本とゲームの通信の部分を流す（終わったら消す）

## 公開後に気をつけること
- 地図（マスの番号・となりの表）は変えない。データベースの `tk/c`・`tk/adj` と合わなくなる
- ルールを変えるときは、変更前に開いたページで遊んでいる人の書きこみがはじかれない形にする
